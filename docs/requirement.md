一、知识库
1. 知识库的增删改查，带分页。
2. 支持上传知识内容，至少支持 txt 或直接输入文本。
3. 相关性查询，输入知识库中的内容，可以查到相应的知识库。（备注，可以使用向量查询）
4. 查询的返回需要流试返回。（跟使用deepseek一样，返回的文字一个个出现）

例子，我上传了朱自清的《春》，鲁迅的《故乡》作为知识库。我搜索“春天”可以搜到《春》，我搜索“少年闰土”可以搜到《故乡》，要可以语义搜索，搜索“小孩子”，一样可以搜到《故乡》


二、Agent开发
请基于 OpenClaw/Claude Code/ Hermas Agent 将你在第一部分实现的知识库查询能力，封装成一个可被 agent 调用的 skill 或 mcp tool / mcp server，二选一即可：
1. 开发一个 skill
2. 开发一个 mcp tool / mcp server

例如：
用户输入“帮我查一下春天相关内容”，agent 可以调用你的 skill 或 mcp，返回知识库里最相关的内容。

要求至少支持：
1. 输入 query
2. 查询知识库
3. 返回相关结果
4. 能被 agent 调用
5. 基本错误处理(如query为空、知识库不存在、检索失败、工具调用超时等)
